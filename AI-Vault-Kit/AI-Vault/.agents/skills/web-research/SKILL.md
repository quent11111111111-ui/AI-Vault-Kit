# Web-Research

## Activation
Information externe, récente ou à vérifier. D'abord vérifier le coffre (`search_simple`) pour éviter de refaire une recherche existante.

## Procédure
1. Reformuler la question en 1–3 requêtes précises (inclure version/date si pertinent).
2. Hiérarchie des sources : documentation officielle / dépôt source > publications primaires > presse spécialisée > blogs/forums.
3. Croiser toute affirmation importante avec ≥ 2 sources indépendantes, ou la marquer « source unique ».
4. Noter pour chaque source : URL, éditeur, date de publication, date de consultation.
5. Repérer les contradictions et les versions (une doc ancienne peut être obsolète).
6. Restituer selon `06_TEMPLATES/Research-Template.md`.
7. Proposer d'ajouter les sources clés à `<projet>/04-References.md`.

## Limites
Ne pas contourner paywalls, CAPTCHA ou restrictions d'accès. Ne pas présenter une opinion comme un fait. Finance : informer, ne jamais donner de conseil d'investissement personnalisé.
